# AgentHarbor 1.1.0

## New

- Template-first studio home with quick actions, featured starters, recent agent activity, and routines.
- Starter library with category filters and six local agent templates.
- Provider setup for OpenAI, Anthropic, Google Gemini, OpenRouter, Groq, DeepSeek, Ollama, and custom OpenAI-compatible APIs.
- Secure API key storage on desktop and Android, with a connection check in Settings.

## Updated

- Desktop, Android, and web screens share the new AgentHarbor workspace style.
- Chat responses distinguish local, provider, and preview replies.
- Product and run instructions describe provider setup and key storage.

## Notes

- AgentHarbor is MIT-licensed and contains no pricing, billing, subscription, or payment interface.
- Routine entries remain saved schedules and prompts; they do not run as background jobs in this release.
- The Windows portable app is unsigned.
