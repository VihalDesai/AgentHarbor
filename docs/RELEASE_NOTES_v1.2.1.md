# AgentHarbor 1.2.1

This update adds the missing template-detail flow so people can review a starter before adding it.

## What's new

- Template cards open a detail page with the agent's role, goal, focus areas, and a clear add action.
- The detail page explains that focus areas are suggestions and do not connect third-party services.
- Provider setup remains available from the detail page.

## Run and build

- Android: install dependencies and run `npm run android` from the repository root.
- Windows desktop: download the portable executable from this release. The executable is unsigned.
- Source: MIT licensed. There are no pricing, subscription, or payment features.

See `README.md` for provider setup and platform notes.
