# AgentHarbor 1.2.0

This release brings the desktop and Android workspace closer to the reviewed Skydive interface while retaining AgentHarbor branding and local-first behavior.

## What's new

- Desktop Home now uses the centered feed and circular quick actions without a persistent left rail.
- Templates and settings use compact dark layouts, with a settings rail for the provider screen.
- Agent profiles use an edge-to-edge original sunset illustration.
- Home now links directly to supported model-provider settings.
- Provider-key storage and chat failures show recovery feedback instead of leaving loading states active.

## Run and build

- Android: install dependencies and run `npm run android` from the repository root.
- Windows desktop: download the portable executable from this release. The executable is unsigned.
- Source: MIT licensed. There are no pricing, subscription, or payment features.

See `README.md` for provider setup and platform notes.
